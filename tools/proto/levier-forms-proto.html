Photo / vidéo du rayonnage — l'état réel

Aucune infrastructure d'envoi de fichier n'existe dans l'app (vérifié : ni stockage objet, ni upload, ni multipart dans les 57 endpoints). Un champ photo dans le formulaire est donc un incrément à part entière, pas une case à cocher.

Ce que vous pouvez tester chez Épices et Tout dès cette semaine, sans une ligne de code : le canal Slack du pôle existe déjà et accepte nativement photos et vidéos. Le responsable photographie son rayonnage avant / après et le poste dans le canal du pôle ; la fiche du dispositif y renvoie. Vous mesurez le geste réel — est-ce que les gens le font ? à quel moment ? est-ce que la photo sert ? — avant de décider si l'app doit porter le fichier elle-même.

Si le test est concluant : l'incrément app serait un champ « preuve » sur le dispositif, et le seul travail neuf est le stockage — le reste (fiche, faire suivre, historique) existe.
